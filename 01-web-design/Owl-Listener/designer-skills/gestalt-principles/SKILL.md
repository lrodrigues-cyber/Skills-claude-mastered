# Gestalt Principles

Pick the principle(s) that match the decision at hand, read only those reference files, then apply them:

1. Name the principle and the concrete UI element it constrains.
2. State the expected user effect (speed, error rate, recall, perceived grouping…).
3. Propose the change, and flag any principle it trades off against.

| Principle | What it says |
|---|---|
| [law of proximity](references/law-of-proximity.md) | Apply the Law of Proximity — spatial closeness groups elements more strongly than any other cue |
| [law of similarity](references/law-of-similarity.md) | Apply the Law of Similarity — shared colour, shape, or size signals that elements belong to one category |
| [law of common region](references/law-of-common-region.md) | Apply the Law of Common Region — a shared container, background, or border groups elements regardless of spacing |
| [law of continuity](references/law-of-continuity.md) | Apply the Law of Continuity — the eye follows alignment and unbroken paths |
| [law of closure](references/law-of-closure.md) | Apply the Law of Closure — the eye completes implied shapes from partial forms |
| [law of figure ground](references/law-of-figure-ground.md) | Apply the Law of Figure-Ground — establish which layer is foreground and actionable versus background |
